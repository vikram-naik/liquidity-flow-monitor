  System Overview                                                                                                                                                                                                                     
                                                                                                                                                                                                                                      
  Data Pipeline: DivergenceEngine.run() produces a ledger DataFrame with ~40+ computed columns (CTS, BT, CWVAP, PSZ, coherence, PDD, regime, etc.) from raw OHLC+delivery data through 6 sequential modules.                          
                                                                                                                                                                                                                                      
  Signal Package (savgol_cts/): CTS mean-reversion signal with 1 entry path orchestrated by SavgolCTSSignal.                                                                                                       
                                                                                                                                                                                                                                                                                                                                                                                                                                                                
  Key Mechanics                                                                                                                                                                                                                       
                                                                                                                                                                                                                                      
  - EOD-lag: signal on bar i, trade opens bar i+1, exits begin bar i+2                                                                                                                                                                
                                                                                                                                                                                                                                      
  Simulation Entry Point                                                                                                                                                                                                              
                                                                                                                                                                                                                                      
  walk_forward.py shows the pattern: load symbols from watchlist DB → DivergenceEngine(sym, start_date, end_date).run() → iterate records bar-by-bar calling check_entry/check_exit with EOD-lag pending mechanism.    

  Virtual Env

  `venv` is defined at the root of the project.  

  Context:

  - Read @SIGNAL_FLOW.md and the @src/trading/signals/savgol_cts/ pkg to build the context. 
  - We backtest the system using @scripts/walk_forward.py script. 
  - The UI is rendered via the @src/web/js/divergence_engine.js and on backend the datastructure for UI is created by @src/divergence_engine/chart.py and the API is served via @src/api/main.py      
  - Any output generated by test or study scripts should be placed under ./output dir.
